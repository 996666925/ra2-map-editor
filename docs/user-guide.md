## 创建地图

### 空白地图

通过“文件 → 新建地图…”或 `Ctrl+N` 创建地图。

| 参数 | 范围 |
| --- | --- |
| 宽度、高度 | 各 20～1004，且宽＋高不超过 1024；最大正方形为 512×512 |
| 初始高度 | 0～127；地图尺寸还须留出可放置玩家起点的区域，过高时创建前会提示调整 |
| 玩家起点 | 2～120 个 |
| 环境 | 温带、雪地、城市、新城市、沙漠、月球 |

尺寸与 VERA20k 扩展格网一致：宽＋高不超过 512 时保留原有 512 格网，超过时使用 1024 格网。

### 随机地图

在“文件”菜单中选择“新建随机地图…”。支持温带、雪地、城市、沙漠和新城市，以及群岛、大陆、海中岛屿、内陆湖泊和山地五种地貌。海中岛屿会沿横向或纵向分开生成两片陆地，适合两队隔海对战。

宽高分别选择八档尺寸，最大档的生成区为 500×500 格；窗口会显示包含边界的实际地图尺寸。支持 2～120 名玩家；超过 8 人时按玩家数量扩大地图面积，并为全部玩家生成起点、安全空地和资源。9～120 人的群岛地图生成多个大岛，让多名玩家共享岛屿。

可以调整水域规模、地形崎岖度、区域连通程度、树林数量、矿区分散程度和资源丰度，并开关矿区、宝石及中立科技建筑。资源档位与游戏的低、中、高、极高四档对应。取消“保留生成的宝石”会将宝石转为矿石。水域等强度数值不等于最终占地百分比。群岛不使用水域规模参数，此时滑块禁用。

“区域连通程度”仅对内陆湖泊和山地生效，控制区域间坡道连接的尝试数量；0 也会尝试连接，不保证所有区域连通。“地形崎岖度”控制后期起伏，0～10 不增加随机高度扰动，但不会消除已有高台、悬崖或岸线起伏。“树林数量”为 0 时仍可能有矿树和地表斑块，温带中该参数还影响部分粗糙地表。“矿区分散程度”通常越大，矿区越多、单片越小，不直接调整玩家起点间距；关闭矿区后，矿区分散程度、资源丰度和宝石控件禁用。

“区域大小”仅对内陆湖泊和山地生效，范围为 0～100；数值越小，大块陆地区域越容易被切分。群岛的科技建筑按游戏规则尝试放在没有玩家起点的岛屿上；包括 9～120 人群岛在内，勾选后也可能没有符合条件的岛屿或成功放置的建筑。

“高级生成设置”可选择光照时段和公平起点，并调整科技建筑数量、废弃军事建筑、损伤、平民密度、动物和中立守军。平民密度设为 0 时，城镇也不会生成平民行人。废弃军事建筑与城镇开关独立，默认按当前规则的建造场、兵营、作战实验室和战车工厂列表选择类型。`RMGMD.INI` 的 `[Extras] Derelicts=` 可覆盖该列表。

开启“生成中立城镇”后，生成器会铺设城区道路，并按当前环境与种子选择民用建筑、平民和车辆。“城镇规模”控制城区数量和覆盖范围；0 不生成城镇，玩家起点保持不变。城镇会改变局部地形，生成对象可像普通地图对象一样编辑和保存。

生成器复用 VERA20k 的随机地图管线，包括随机地块生长、水域整形、岸线拼接、区域划分、起点选择、矿区扩散、山地与地表过渡、树林散布。生成在后台进行，完成后得到可编辑、待保存的新地图。

重新打开窗口会保留本次编辑器会话中的参数和种子，也可手工指定种子或点击“换一个”。切换地貌保留手调参数；点击“应用推荐参数”仅按当前地貌重设水域规模和地形崎岖度，其他参数和种子保持不变。相同版本、游戏资源、参数和种子可复现结果。缺少玩家起点的候选地图会自动跳过，最多尝试 16 次；地图的 `[RandomMap]` 节保存最终种子和完整参数，`EditorRequestedSeed` 保留最初输入的种子。若极端参数仍无法容纳全部起点，会提示调整参数或更换种子。

## 地图拼接与多地图管理

打开或新建地图后，点击主画布上方的“多地图模式”，或选择“文件 → 多地图模式”。也可通过“文件 → 导入地图到当前地图…”进入模式并选择 `.map`、`.mpr` 或 `.yrm` 文件，支持一次选择多个文件。

地图直接显示在编辑器原有的大地图画布中，保留真实地形、高度、桥梁、建筑和对象的渲染。左侧工具栏切换为地图图层列表，每张地图独立保存其内容：

1. 点击画布上方的“导入地图…”。导入地图默认居中叠放在当前地图上，覆盖对应位置的显示。
2. 在左侧选择图层，直接在中央大地图上按住左键整体拖动；地图按格子吸附，松手保留位置。当前地图也可整体移动，左侧 X / Y 偏移可精确对齐位置。
3. 每张地图的地形和对象在导入后缓存，拖动时直接平移完整画面，无须反复合成或加载整张地图。移开后，下层原有内容立即显现。`Esc`、右键或窗口失去焦点取消本次拖动，之前完成的布局保留。
4. 滚轮缩放，按住空格拖动或使用中键平移；“适应地图”显示全部图层。移出原地图边界后可继续拖动，预览扩展时保持当前镜头位置。
5. 左侧“上移一层 / 下移一层”调整覆盖顺序，“移除所选地图”移除导入图层并露出下方内容。
6. 点击画布上方“完成并返回编辑”，将当前图层布局写入地图并恢复普通编辑工具；超出原图范围时自动扩展尺寸。`Ctrl+Z / Y` 可撤销、重做整次应用，再正常保存地图。重新打开文件后，再进入多地图模式仍可继续移动或移除独立图层，露出位置的原有内容仍可恢复。

允许导入不同地形环境的地图。地形编号、子块、高度和覆盖物帧原样迁移，最终地图使用当前地图的环境与游戏资源，因此跨环境导入的地形外观可能变化。

列表靠后的导入地图覆盖前面的地图，覆盖范围包含空地和空覆盖物；原有建筑、单位、树木和污迹仍保存在下方图层中，移走上层地图即可露出。只有应用后的合成结果会采用上层内容。当前地图的航点编号保留，导入航点使用从 30 起的新编号。导入对象保留属性和桥面标志，地图内部的车辆跟随关系重新绑定；导入对象的关联任务标签清空。

当前地图的任务、规则、光照、格子标签等设置保留，已有空间引用随当前地图迁移。导入地图的任务定义、规则、基地节点和隧道路径不参与导入。拼接后的可玩区域自动扩展，可通过“设置 → 地图尺寸与光照…”进一步调整；最终宽＋高不能超过 1024。

点击“完成并返回编辑”前，布局属于预览草稿，不修改地图内容。应用时，独立地图内容、名称、覆盖顺序和偏移会压缩保存在地图的 `[YRMapEditorLayersPack]` 编辑器专用节中，与合成结果一起保存，另存为或移动文件无需额外的项目文件。地图在游戏中仍使用合成结果。未应用的布局草稿不随文件保存。

普通编辑修改合成结果后，再进入多地图模式会从当前地图重新建立图层，避免旧图层覆盖后续编辑。撤销恢复到原布局对应的合成结果后，可以再次恢复独立图层。

## 编辑地形

画布默认显示地图边界线：红线表示完整地图范围（`Size`），按外圈地块的实际高度和完整菱形范围绘制矩形；内陆高山及建筑不会扩大红框。2D 视图按压平后的地块范围绘制红框。蓝线表示可玩区域（`LocalSize`）的零高度逻辑参考范围。右侧“显示图层 → 地图边界线”可切换显示，普通、框架和 2D 地形视图均可使用。边界线随平移和缩放移动；修改地图尺寸、边缘地形或可玩区域后，边界线随地图预览更新。

顶部工具栏提供常用工具，左侧显示参数与素材；地形按“地表、悬崖、水域、道路 / 桥”分组。自动工具无需手工挑选地形素材，“手工拼贴地形…”可转入完整模板编辑。

一笔操作形成一次撤销。拖动时检查预览，松手提交，`Esc` 或右键取消，`Ctrl+Z` 撤销整笔。后台预览更新期间保留当前地图画面，准备完成后切换。

### VERA 可破裂冰面

在 `NewINIFormat=4` 的雪地地图中，打开“地图设置 → 地图信息 → 资源与环境”，开启“使用 VERA 可破裂冰面”。资源加载后，左侧“地形 → 水域”会出现“可破裂冰面”。可用“框选铺冰”框住一片水面，或用“涂抹铺冰”选择 `1×1` 至 `9×9` 的笔刷自由涂抹。工具会连接相邻冰面，并在周围同高度的深水格上预览直边和转角；这些过渡格仍按水域通行。浅滩、海岸、坡道、有覆盖物或有对象占地的格子保持不变。松手提交整笔，可撤销。需要指定冰面样式、裂纹和雪岸时，可在“手工拼贴地形”中搜索 `VERA Ice`。

“临岸碎冰过渡”默认开启。宽冰面贴岸时，工具会用一格碎冰水域柔化直边、转角和连续的阶梯尖角，不替换原版岸线。窄冰道优先保留与岸边的连接。碎冰过渡格按水域通行且不再冻结。自动铺冰会按格子位置混用同形状的碎冰纹理，重刷已铺好的冰面可更新边缘。需要陆军能沿冰面直接接岸时，关闭选项再重刷接岸处。

“铺冰时标记可再冻结”控制铺下的实冰，默认开启，关闭后保留各格原有标记。也可用“区域选择”单独标记或清除。“允许冰层生长”控制整张地图是否启用生长，格子标记控制哪些格子可重新冻结。冰面的破裂和冻结在 VERA20k 试玩中发生。

用“水域”或“折线水域”覆盖实冰、裂冰或碎冰，可以将它们刷回水域并清除再冻结标记。相邻实冰保留，冰缘随新轮廓更新；没有实冰支撑的旧碎冰边退回普通水面。关闭“使用 VERA 可破裂冰面”前，需要先替换地图上仍使用的 VERA 冰面、碎冰过渡和雪岸素材。

源码构建会读取子模块里的 `Terrain`。便携编辑器需要自备同版本 VERA20k 的资源：将包含 `vera_ice.mix` 和 `vera_ice_tiles.ini` 的 `Terrain` 文件夹放到编辑器可执行文件旁边。冰面地图使用 VERA20k 0.4.2 开发版的地形扩展，试玩程序也需要对应的资源包。

### 框选与涂抹铺地

- `B` 进入地形画笔，拖动连续涂抹。
- 放置地形、资源和覆盖物画笔按住 `Shift` 可锁定地图轴向：从起点沿较接近的地图轴移动，方向确定后保持锁定；松开 `Shift` 恢复自由绘制。拖动中再按 `Shift`，会从上一落点开始锁定。连续坡面工具中 `Shift` 为陡坡，`Alt+Shift` 可锁轴画线。
- 手工画笔 / 模板中，`Ctrl` 点击按相连同类平坦地表填充，包含常见 LAT 过渡，保留各格高度；悬崖、水岸和坡道使用专用工具。`Ctrl+Shift` 放置时关闭本笔自动 LAT。`Alt` 拖动直线，回拖或改变终点会回撤旧线段。
- `G` 进入铺地并选择素材。“框选铺地”用左键拖出矩形，单击只铺一格。“涂抹铺地”可设置 `1×1` 到 `9×9` 的方形笔刷，按住左键沿任意路径涂抹。
- 拖动时预览材质和格数，铺地保留每格高度。松手提交整笔，`Ctrl+Z` 撤销；`Esc` 或右键取消未提交的操作。
- 橙色标出保留的坡道、悬崖、道路、水域和水岸；自动 LAT 的邻格过渡调整以浅蓝色显示。

### 悬崖、高台与坡道

手工选择完整悬崖模板时，默认用相对高度最低的有效子块对齐鼠标，切换上一块 / 下一块也采用该规则。未指定基准高度时，最低子块跟随鼠标下的地面高度；需要接续高台时，可以在锚点菱形中手动改选高侧子块。

点击画布上方“框架”或按 `Ctrl+F`，可切换类似 FA2 的框架显示：悬崖、转角和坡道使用简化素材，左侧完整模板、子块缩略图和放置预览同步切换，方便按形状拼接。框架模式保留高度和遮挡关系，对象、区域等编辑工具仍可使用。

“框架”和“2D 地形”互斥：开启框架会关闭 2D，开启 2D 会关闭框架；关闭当前模式后返回普通立体视图。游戏目录或其 `FinalAlert2` / `FinalAlert2YR` 子目录存在 `marble.mix` 时，使用其中与当前地形几何兼容的 FA2 框架素材和高度图；其他地形自动生成简化外观。切换显示不会改变地图中保存的地形编号和高度。

点击画布上方“2D 地形”或按 `F2`，可将地形铺平编辑。这个视图保持菱形格子的方向，去掉高度造成的屏幕位移，方便对齐悬崖的背面、转角和相邻模板；地图实际高度保持不变。再次按 `F2` 返回立体视图检查崖壁外观。

- 关闭框架时，格子颜色表示高度，悬崖为棕色，水面为蓝色，道路为灰色。放大后显示实际高度，数字后的 `/` 表示坡面；开启框架后显示简化地形素材。
- 金线标出相邻格子的高度变化，蓝线标出完整地形模板的外沿；进一步放大可看到模板编号和子块编号，方便配合左侧素材库手工拼贴。
- 完整模板、子块、升降、平整，以及高台、悬崖轮廓、坡道、水岸、道路、桥梁的自动工具均可使用。绿色预览显示修改格子，红色提示无效位置；松手提交，`Esc` / 右键取消，`Ctrl+Z/Y` 撤销与重做。
- 红叉表示对象占地，红点表示覆盖物。2D 是地形工作视图；选择对象、区域、资源等其他工具时自动返回立体视图。
- 右侧可关闭高度数字或模板边界。平移、缩放、地图导航、`Home` 适应地图、`F` 定位所选格子继续可用；拖动期间不能切换视图。

建议先在 2D 视图用 `C` 围合悬崖、`H` 生成或扩建高台，再用坡道工具补入口；需要精细拼贴时选择“手工模板”，根据模板边界对齐，最后切回立体视图检查效果。2D 的颜色和轮廓用于编辑几何，地图保存与导出仍使用真实地形。

使用“围合悬崖”（`C`）描绘轮廓，或用正面 / 背面悬崖画线；用矩形高台（`H`）扩建，再插入坡道入口。悬崖和坡道支持最高 127 层的正高度，标准悬崖高差为 4 层，低地基准可指定为 0～123 层，也可从已有地形自动识别。使用“坡道入口”时，在直线悬崖边缘按住左键，沿边缘向任一侧拖动即可加宽；宽度按完整地形模板吸附，松开后一次生成，可整笔撤销。点在矩形高台角落时，会将拐角本身转换为向外下降的连续坡面，并衔接两侧悬崖；沿任一地图轴拖动可加宽对应一侧的坡面。直边与拐角坡道相接时，同高度、同坡向的入口会自动合并，去掉连接处的收口；保存重开后也可继续从已有入口拖动扩展。

悬崖线段、折线、围合悬崖和矩形高台都可以直接画在平坦水面上。生成的高台内部会变成陆地，临水正面会优先使用当前环境可用的水悬崖模板。临水直坡在有空间时向外接一小段同高地面，两侧沿崖脚接入原版岸线圆角，中间和两侧的草沙交界都使用原版过渡图块。空间不足或遇到转角时，仅在坡脚局部收边。点击已有的自动坡道，可重拼岸线；地形与过渡图块都随地图保存。

### 切除高台

从顶部工具栏或左侧“悬崖”页选择“切除高台”，在左侧“切除方式”中选择操作。

- **矩形拖选**是默认方式。按住左键拖到对角格，松开后将选区内的高地降到低地基准，修补剩余边界。框住整个高台可整块移除。低地高度可自动识别，也可手动指定。
- **两点切线**先点悬崖下方的低地，再把鼠标移向高台，让切线穿过崖壁并显示预览。切线旁的短刻度标出要削掉的一侧。预览时可切换左右和调整目标高度，第二次点击提交。用 `F2` 切换到 2D 地形更容易对齐两点。

两种方式都支持 `Esc` 或右键取消，以及 `Ctrl+Z/Y` 整笔撤销与重做。提交或取消后可切换切除方式。

**两点切线**以两点之间最先穿过的崖壁确定连通高台，再向两端延伸切线。切线上的高地格归保留侧。默认降到崖脚并重建剩余崖壁。“指定削切高度”可选崖脚到崖顶下一层的实际高度。中间高度会在切掉的一侧留下所选高度的平地，并用坡面接到周围地面，崖壁仍采用标准四层模板。区域太窄或改动范围碰到受保护地形、对象或覆盖物时，红色预览会提示原因。

### 保留悬崖填高地

对于先手工拼好悬崖、内部尚未升高的区域，选择顶部或左侧“悬崖”页中的“填高地”。先点击一块悬崖或已有地面拾取目标高度（点击悬崖低侧也会取该模板的最高层，单独放置的子块也可取样），再点击围合区域内部：按住左键查看预览，松开后整片填高，`Esc` / 右键取消，`Ctrl+Z/Y` 撤销与重做。可点击“拾取高度”重新取样，或直接输入 0～127 层的目标高度。

工具只修改起点所在的同高度、四方向连通平地，保留材质、悬崖、坡道、道路和水岸。不同高度或结构地形会阻断填充；区域通向地图边缘时拒绝提交，需先闭合边界。需要改变高度的格子有对象、建筑占地或覆盖物时，也会整笔拒绝。

按 `F7` 进入“平整高度”，在希望保留其高度的地面或悬崖子块上按下左键，然后按住拖刷。默认每笔取按下处的实际高度，并在本笔期间保持；后续每笔会重新取高。拖动时预览刷平后的地面和坡面，松手整笔提交，`Esc` / 右键取消。勾选“固定目标高度”可输入目标值，或点“拾取高度”单独取样后连续刷多笔。

大笔刷只处理当前鼠标所在一侧、在本次笔刷窗口内连通的可塑地面，不因方框覆盖崖的另一侧就一并修改。主动把鼠标移到另一侧后，可以继续刷那一侧。崖壁、道路、水面、覆盖物和对象占地会阻挡或限制刷平；坡面只沿可处理的地面衔接，碰到仅对角相接的崖壁也不会借公共角点穿过去。

`F6` 切换降低；地形模式下 `F5` 切换升高，其他模式下 `F5` 打开试玩设置。普通格子模式点击悬崖会直接升降完整模板，无须先关闭自动坡面；按下时按住 `Ctrl` 可扩展到相连的同组悬崖，忽略笔刷大小。保持子块间高度差，模板不完整、高度不一致或整块升降越过 0～127 层时不提交修改。

升高 / 降低可切换“按层数升降”和“指定目标高度”：前者输入每笔改变的层数，默认 1，普通模式以按下处高度为参考直接处理同高格；后者输入最终高度，升高只处理低于目标的地面，降低只处理高于目标的地面。整块悬崖的目标高度指崖顶，子块之间的高度差保持不变。连续地面坡面的最终高度范围为 0～12；原始改层和完整悬崖为 0～127。参数在按下时固定，拖动重访同一格不会重复升降，整笔可撤销。

开启连续坡面时，`Shift` 生成陡坡，`A` 或“顶点模式”切换为单独调整顶点；顶点模式升高时处理不高于起点的顶点，降低反之。`Ctrl+Shift` 强制塑形可改变悬崖、道路、水岸等结构地形，仍保护对象和覆盖物占地。上述模式在按下时固定，松手前可检查范围，`Esc` 取消。刷平模式中，鼠标所在处可用 `↑ / ↓` 临时升降一层，每次可单独撤销，不改变固定刷平目标。滚轮始终用于缩放地图。

升降预览会显示整块模板及周围坡面的实际变更范围，2D 视图显示预计层数；模板不完整、越界或坡面目标冲突时提前显示错误，松手不修改地图。选区混合高度无法同时衔接连续坡面时，可缩小范围，或关闭自动坡面直接改层。预览与提交使用同一计算结果，包含自动地表过渡。

“平整高度”保留崖壁子块，改变崖壁基准请用下面的专用工具。注意两种取高方式：“填高地”和单独的“拾取高度”会推导标准悬崖的崖顶；平整画笔每笔按下时，像 FA2 普通地表模式一样记录所点格的实际层数。需要取崖顶时应点高侧子块。

### 子块悬崖的高度

悬崖贴图本身画有崖壁，不能仅凭外观判断内部是否已经抬高；框架地面的数字才表示该格实际层数。“子块画笔”绘制悬崖时，会按低地基准加上模板中该子块的相对高度，重复涂同一子块不会叠高。普通地表画笔仍保留原格高度。

旧版本用子块画笔拼出的悬崖可能所有子块都保留了原地面高度。选择左侧“悬崖 → 修正悬崖高度”，设置**低地高度**，拖框选中整圈悬崖，按住检查预览，松开修正。它只调整框内悬崖子块高度，不替换图块、不补齐模板、不改变内部地面，可整笔撤销；修改格有对象或覆盖物时拒绝提交。零层地面上的悬崖设为 `0`，修正后再用“填高地”把内部升到 `4` 层，在框架视图中检查内 `4`、外 `0`。

修正工具的低地参数独立于高台和完整模板工具。多层悬崖需按各自低地基准分别框选；已有子块高度无法解释时，先显式修正，再重绘或取高。

完整模板、子块和自动悬崖放置中，可用 `PageUp / PageDown` 调整固定基准高度；预览和保存使用同一个值。取消“指定模板基准高度”“指定低地基准高度”或折线工具的“指定基准地面高度”可恢复跟随地面。仅高侧子块的背面模板默认不会反推到负基准；所有悬崖放置都检查推算崖顶是否超过上限。

### 折线悬崖

选择左侧“悬崖 → 折线悬崖”，先在“高侧方向”下拉框中选择绘制方向的左侧或右侧，再依次点击起点和折点。黄色线显示路线，箭头指向高侧；崖壁高差为 4 层。默认以起点地面为基准，也可用“指定基准地面高度”手动设置。

- **开放折线**：至少确认两个折点后按 `Enter`，只沿已确认的路线放置一侧崖壁，周围地面保持原高度。不生成坡道、填高区域、背侧崖壁或末端封口。鼠标悬停处为待确认线段，需点击才加入路线。
- **闭合轮廓**：点击起点完成闭合，自动拼接整圈崖壁。外侧地面保持原高度，内部根据绘制方向与高侧选项统一升高或降低 4 层。

| 画布上的绘制方向 | 高侧方向 | 闭合结果 |
| --- | --- | --- |
| 顺时针 | 右侧 | 高台，内部为基准 + 4 层 |
| 顺时针 | 左侧 | 坑，内部为基准 − 4 层 |
| 逆时针 | 左侧 | 高台，内部为基准 + 4 层 |
| 逆时针 | 右侧 | 坑，内部为基准 − 4 层 |

闭合时，轮廓紧邻的外侧地面须与基准高度一致。生成坑要求外侧地面至少为 4 层，否则提示先抬高地面；不会自动抬高外侧。高台和开放崖壁的基准范围为 0～123 层，坑的外侧基准范围为 4～127 层。

`Backspace` 撤回最后一个折点，`Esc` / 右键取消整条草稿。预览期间不修改地图；提交后可整笔撤销、重做。开放折线的修改范围仅为完整悬崖模板的占地，闭合后才统一内部高度；转角过密、折线自交、模板越界、资源缺失或有对象/覆盖物占用时拒绝生成，可撤回折点修正后继续。

### 水域与岸线

矩形和围合水域会自动拼接岸线。环境提供对应地表素材时，还会补齐沙滩外缘与草地之间的过渡，包含四边和转角。已有水域可用“修复岸线”补齐缺损和过渡。调整画笔宽度后，按住左键沿岸刷过，松开应用，Esc 取消。修复会优先保留水域形状。单格锯齿无法拼接时，会尝试在刷区内按 2×2 格微调水陆边界。邻格的衔接修改随整笔操作一起撤销。

围合水域遇到无法拼接的一格斜边或细小折角时，会按 2×2 格向外规整轮廓，每轴最多补一格；可直接拼接的轮廓保持原样。拖动时显示实际生成的水面与岸线，松手提交预览结果。

选择“水域 → 折线水域”，逐次点击添加折点。点击起点直接闭合并生成水域。按 `Enter` 会用直线连接最后一个已确认的折点和起点，再填充内部。顺时针和逆时针画出的水域相同。凹边可以保留，至少需要三个不同的折点，闭合后的边不能交叉或重叠。预览显示已确认折点闭合后的水面与岸线，岸线规整与围合水域相同。无效的草稿可补画或用 `Backspace` 撤回折点。`Esc` / 右键取消，生成后可整笔撤销、重做。

### 桥梁

“架设桥梁”提供混凝土、木质的高桥与低桥。

| 桥梁 | 适用地形与要求 |
| --- | --- |
| 悬崖间高桥 | 从一侧高地或悬崖拖到另一侧，端点自动贴合崖边；两岸等高，桥面高度由两端桥头确定，桥下地形可用普通高度工具编辑 |
| 水面低桥 | 用于平地河流；两岸与水面等高，端点可落在岸边并自动向陆地接齐 |

拖动会吸附地图轴向，预览绿色时松手放置。低桥在跨水拖动时始终显示到鼠标位置的完整桥面，端点未接岸时为红色，接齐有效陆地后变绿。

桥头需有足够宽的平坦通路。高桥桥身可跨过桥基高度或更低的普通坡面，并保留原地形。已有对象、覆盖物和不兼容的地形会阻止放置，并提示原因。

### 绘制道路

在左侧「道路 / 桥」分组选择「绘制道路」，再选择当前环境提供的铺装公路或土路。按住左键拖出一条中心线，预览后松手铺设整段道路。斜向线段由直道和弯道拼接，按住 `Shift` 可锁定地图轴向。接入同类型的已有道路时会自动拼接弯道、T 字路口或十字路口。

选择「连续画路」可把多条线段接成一条路线。点击起点，然后逐次点击下一点，或拖到下一点后松手。按住 `Shift` 锁定当前线段的轴向。`Backspace` 撤回最后一段，`Esc` 或右键取消。按 `Enter` 或点击「铺设路线」，一次生成所有已确认的路段。整条路线可一次撤销。

要铺上坡或下坡，先让地形形成覆盖整个路宽的一层直坡，然后把线段沿坡向拖过两端，接到平地。剧场缺少对应坡向素材、路口过密或目标格被占用时，预览会显示原因。`Esc` 取消，`Ctrl+Z` 撤销整次铺设。「切除道路」可移除同类型的平路并修补端点。

### 隧道路径

按 `T` 打开隧道工具，或从顶部工具栏选择“隧道”。点击“新建隧道”，在画布先点入口，再沿路线逐格点击或拖动；选好出口朝向后保存。路线使用八方向格步，最多 99 步。保存时在地图的 `[Tubes]` 中写入正向路径，出口格空闲时补写反向路径，让引擎能从两端通行。编辑器把自己创建的两条记录显示为一条隧道，可一起重绘、删除、撤销和重做。入口通行方向由路径第一步确定；出口朝向选择原版门洞素材和画布箭头方向，单独保存在 `[TunnelPortalFacing]`，不改动入口通行方向，也不承诺改变单位出洞后的朝向。选中已有隧道后也可直接修改出口朝向，修改立即保存并支持撤销。检测到当前剧场有完整入口素材时，保存会自动在路线两端铺设对应方向的洞口地形，将通行端点对齐到素材的隧道格或门前道路格；也可关闭自动放置或切换地形组。雪地、温带、城市、新城市和沙漠剧场均有隧道素材，月球剧场没有。

试玩时先把坦克移动到绿色“入”标记的通行格，到达后再命令它移动到橙色“出”标记。当前引擎直接点击远端出口时可能选择地面绕路。出口素材本身不会自动生成反向路径。

左侧列表会显示已有隧道的入口、出口和步数。选中一条可在地图上高亮；点击“重绘所选”进入替换模式，画布暂时隐藏旧路线，重新绘制后按“保存隧道路径”更新 `[Tubes]` 记录。重绘旧单向路径时，编辑器可补齐空闲出口的反向记录。“删除所选”移除选中的隧道。旧地图中独立保存的两条往返路径会提供“删除两条往返路径”按钮，一次移除两个方向。保存、重绘和删除都支持撤销与重做。如果另一条路径仍依赖这个洞口出洞，须先重绘或删除依赖的路径。裁剪地图时也会检查保留路径的出口记录。右侧“显示图层 → 隧道路径”可切换路线显示；使用隧道工具时路径与绘制预览始终可见。

此工具编辑地图中显式保存的 `[Tubes]` 路径；桥梁等地形生成的低桥通道仍由引擎自动构建。编辑器会备份自动铺设洞口下方的地形，备份随地图保存，关闭重开后重绘或删除仍能恢复；洞口格后来被手工修改时保留该修改。旧地图没有这类备份时，仅把完整匹配原版洞口模板的地形恢复为清地形。若洞口覆盖到对象、覆盖物或另一条隧道的洞口，路径仍会保存，但本次不会自动铺设洞口并会显示原因。修改已有隧道的出口朝向会一起更新洞口素材，整次操作可以撤销。

## 放置对象与区域编辑

### 单击放置与拖动连刷

选中对象素材后单击放置，或按住左键沿地图拖动连刷；快速移动时会补齐沿途格子。同一笔按实际占地去重，遇到占用、越界或建筑高低不平的位置自动跳过。

按住 `Shift` 拖动可沿一个地图轴向连刷；首次移动确定方向后保持锁定，回拖可缩短当前线段，越过起点可反向绘制。地形和资源画笔也支持这种伸缩操作。松开 `Shift` 保留当前线段并恢复自由连刷。拖动中按下 `Shift` 会从上一落点开始锁定，之前刷过的部分会保留。离开地图画布后重新进入，会从新位置继续，不跨越画布外的间隔补刷。

对象类型、所属方、步兵子格和重叠选项以按下鼠标时为准。拖动中显示对象预览，松手提交；`Esc` / 右键取消整笔，`Ctrl+Z` 整笔撤销。

### 选择与区域操作

在选择工具（`V`）下，直接点击画布上的对象、起点或航点，拖到目标格后松开即可移动；也可以先点选，再点击目标格放下。移动前显示连线与占地预览，`Esc` 或右键取消；完成后自动返回选择工具。对象保留原属性，航点保留编号与任务引用；支持撤销、重做和保存。目标无效时显示红色占地，不写入修改。

按图层选择区域后，可复制、剪切、粘贴、移动或删除；区域选择时使用 `Shift` 添加、`Alt` 减选。对象可通过 `Ctrl+D` 克隆；复制、剪切、粘贴和删除快捷键见 [常用操作](../README.md#常用操作)。

### 开局交给起点玩家

选中建筑、车辆、步兵或飞机，在对象属性的“开局交给”中选择“航点 N 的玩家”，即可在开局转交给使用该起点的人类玩家或电脑。

- 支持地图上已定义的航点 **0～119**；8～119 为 VERA 扩展起点，需在“设置 → 地图信息”中配置相应出生点数量。
- 启用后初始所属方设为 Neutral（中立）；目标起点无人使用时保持中立。
- 选择“保持所属方”可取消转交；恢复启用前的所属方请使用撤销。
- 自动维护标准地图触发器，多个对象可交给同一起点，修改和取消支持撤销，并随地图保存。

对象已有自定义关联标签时，请通过任务触发器配置，避免覆盖原有行为。

## 地图与任务设置

### 表单输入与自动生效

对象属性、任务参数和光照在结束输入后自动生效：文本按回车或移开焦点，数值拖动松手后生效，勾选和下拉选择无需额外确认。每次完成的编辑可撤销；无效输入留在表单中提示，可修正或取消本次输入。

对象类型、所属方和任务引用字段支持输入补全，可搜索 ID 或显示名称。使用方向键选择，`Enter` / `Tab` 接受，`Esc` 关闭候选；仍可手工填写模组扩展值，也可使用原有下拉列表。

`Ctrl+S` / `Ctrl+Shift+S` 会先提交有效输入，再保存 / 另存。无效值与未应用的尺寸或生产限制草稿会阻止保存。输入框保留自己的文字撤销、复制和粘贴操作。

自动生效写入当前地图文档，保存到磁盘仍需 `Ctrl+S`。修改地图尺寸后，点击“应用地图设置”。编辑器会检查越界内容，可移除的越界内容须勾选删除才会移除，有航点等阻塞项时须先调整。应用结果可整笔撤销。关闭地图设置窗口时，有效的自动生效输入会提交，无效输入和未应用的尺寸或生产限制草稿会丢弃。

### 地图名称与出生点

在“设置 → 地图信息…”中修改地图名称、作者署名、开局基地车和出生点数量。

地图信息使用统一的分组表单，“基本信息”默认展开，包含名称、作者、出生点与地图说明；其他分组按需展开。字段说明可悬停查看。

| 分组 | 设置 |
| --- | --- |
| 基本信息 | 名称、作者、出生点、多行说明、适用游戏模式、最低人数、官方标记、多人地图标记 |
| 资源与场景规则 | 矿石生长、冰层/藤蔓场景标志、Ares 变异体开关、免费雷达、矿仓、火车/卡车箱子、全局 AI 触发器 |
| 特殊规则 | 基地车展开、初始单位精英化、矿石变密/扩散、桥梁、世界伤害、迷雾和矿车自动索敌保护 |
| 单人任务与战役流程 | 玩家 House、初始视野航点、后续任务、计时与资金继承、评分和战役结束流程 |
| 音乐与过场动画 | 开局音乐，以及开场、简报、任务开始、胜负、评分后和选图前影片 |
| 多人开局默认值 | 资金、部队数量、科技、速度、桥梁、黑幕、矿石、箱子、矿车停战、工程师、结盟、快速游戏、超武、盟友建造和基地车重新部署 |

布尔项可选“使用默认值 / 开启 / 关闭”；人数、资金、数量和科技等级使用数字控件，取消“使用默认值”后可拖动或输入，资金继承比例直接按百分比调整，上限可勾选“不限”。游戏速度按中文档位选择。所属方和航点从当前地图选择，音乐与影片从当前游戏 / Mod 的目录选择，均提供搜索和“自定义…”输入；后续任务可点“选择地图…”选取文件，写入文件名。适用游戏模式可多选，候选来自安装目录的模式配置，自定义模式仍可编辑。

选择默认或清空自定义值会删除对应覆盖，不会把引擎默认值写死进地图；打开面板不改动数值，未编辑的未知 Mod 原值保持原样。多行说明保存为引擎使用的 `@` 分行格式，与 `Brief` 简报影片不同。修改在结束输入时自动生效，支持取消、撤销、重做及保存前提交；无效输入不会部分写入地图。

多人默认值可能被启动器、房间或试玩设置覆盖；遭遇战的部分特殊规则也由房间接管。Ares 变异体选项仅在引擎启用相关 Ares 行为时生效。冰层和藤蔓标志可读写场景状态，当前引擎尚未实现对应生长模拟；矿车免于自动索敌不代表免疫伤害。地图格式版本由编辑器维护，不作为普通信息字段修改。

新建地图时可填写作者署名，也可留空。署名支持中文，最多 127 字节。“开局有基地车”位于地图信息的“多人开局默认值”分组，与同组开关一样使用“使用默认值 / 开启 / 关闭”下拉框。选择默认会删除地图中的 `Bases` 覆盖，由游戏或 Mod 决定；原版默认开启。启动器或房间设置可能覆盖它，不影响手动放置的单位。

地图名称支持中文，不能为空，最多 120 字节，不能包含分号或控制字符。按回车或移开焦点后自动生效，支持撤销、重做和保存前提交。

出生点数量可设为 2～120 个。增加时补齐缺少的起点并保留已有位置，减少时删除多余出生点；其他任务航点保留，可用航点工具调整位置。

编辑器的离线 `-SPAWN` 遭遇战试玩可用航点 0～119，最多容纳 1 名玩家和 119 个电脑。试玩起点须从航点 0 连续编号，缺号后的起点不会出现在试玩选项中。传统预览沿用引擎的八个起点标记，只绘制航点 0～7。

### 生产限制

打开“设置 → 生产限制…”，勾选要限制的类别，再点击“应用生产限制”。可限制空军、海军、陆地载具、步兵、全部建筑、防御设施、超级武器设施、间谍及偷科技单位。可以多选，也可取消勾选以恢复原规则。整次调整可撤销，`Ctrl+S` 写入地图。

类别按当前游戏和 Mod 的引擎规则识别。多人地图包含匹配 `GameMode` 的已安装模式。各模式共用地图内的一份限制，同一类型在任一匹配模式中属于所选类别，就会写入限制。游戏资源或地图规则发生变化时，可保留勾选并重新应用。

空军包括飞机、飞行步兵和飞行载具，海军包括 `Naval=yes` 的载具。超级武器设施保留 `BuildTech` 例外。地图写入生产资格和建造上限的覆盖，并备份原值。受限建筑同时从地图预写的 AI 基地计划中暂时移出，在编辑器里仍可编辑，解除限制后会按原顺序恢复。预置对象和任务直接生成的对象仍可使用。引擎运行时为 AI 强制加入的建筑、部分 Mod 绕过建造上限的生产路径，仍取决于游戏或 Mod 自身的规则。

### 箱子规则

“设置 → 箱子设置…”可单独调整当前地图的箱子规则，包括数量上下限、随机刷新间隔、效果范围和单人金钱奖励。

| 设置 | 行为 |
| --- | --- |
| 最少和最多数量相同 | 指定开局箱数，实际数量还取决于可放置位置 |
| 最多数量为 0 | 禁止开局随机生成 |
| 刷新间隔 | 单位为游戏分钟，越小刷新越频繁；未拾取箱子约在 0.5～2 倍间隔内随机换位，拾取后尝试立即补充 |
| 字段留空 / 全部继承游戏或 Mod 规则 | 移除地图覆盖，沿用游戏规则 |

遭遇战或试玩需同时开启“随机箱子”。修改结束输入后自动生效，支持撤销、重做和保存前提交。

### 任务制作

任务编辑支持 House、触发器、Tag/CellTag、变量、特遣部队、脚本、小队、基地节点与 AI 触发器。

在顶栏打开“扩展系统”，点击“新建项目…”，填写项目名称并选择位置，再点击“创建项目”。不需要先打开地图。新项目使用一份根目录 `package.json` 管理依赖，并以 `"vera": { "kind": "extension" }` 标识扩展项目，逻辑入口为 `rules/src/main.ts`，界面入口为 `ui/src/main.ts`，公共协议放在 `shared/protocol.ts`；一次构建输出 `dist/rules.wasm` 和 `dist/ui.wasm`。也可以用 [create-vera-app](../crates/create-vera-app/README.md) 从命令行创建项目。

编辑器不附带 Node.js 或 AssemblyScript 编译器。安装 Node.js >=22.15（含 npm），在扩展项目根目录执行 `npm install`，再回到编辑器点击“构建”。编辑器使用系统 Node.js 调用项目内的 `@ra2-map-editor/mission-wasm-build` 构建器。

打开地图后，窗口分别显示 `rules.wasm` 和 `ui.wasm`，可独立导入、导出或移除；“构建并嵌入”会将联合项目的两个模块一起校验并提交，任一失败均不更新地图，一次撤销即可恢复两个模块。单模块项目根据 `vera.json` 类型只更新对应模块，保留另一模块。导入时使用固定引擎的模拟或客户端沙箱校验，更新可整笔撤销。保存地图后，模块随地图进入 VERA20k 的试玩流程。逻辑模块负责同步游戏状态，界面模块只在本机运行；界面要修改游戏状态时，应向逻辑模块发送请求，由逻辑模块校验并执行。

成功导入或“构建并嵌入”后，编辑器会在本次会话中监听对应的 Wasm 源文件。文件内容稳定且校验通过后，提示是否重新导入；选择“暂不导入”后，同一版内容不会重复提示，后续修改仍会提示。关闭扩展窗口不影响监听；移除模块、撤销导致模块被替换、切换或关闭地图后停止对应监听。重新打开地图时需再次导入源文件以建立监听。

安装依赖后，也可在扩展项目根目录运行 `npm run check` 检查类型、`npm run build` 构建两个 Wasm，或用 `npm run build:rules`、`npm run build:ui` 单独构建。详见[命令行构建](cli.md#wasm-扩展命令)。

原生任务表单可创建地图内的 House、航点、触发器、小队和 AI 定义。Wasm 模块可调用现有小队执行增援，也可写入 Local 变量供地图触发器读取。接口和示例见 [引擎 TSSDK 发布包](../crates/vera20k-sdk/README.md)。

## 保存与恢复

`Ctrl+S` 后台保存当前地图，并生成内嵌 `PreviewPack`；保存后会重开校验，保留最多三份 `.yr-editor-*.bak` 备份。已有内嵌预览会在重新保存时更新。

空闲后自动生成恢复快照。Windows 默认位置为：

```text
%LOCALAPPDATA%/ra2-map-editor/recovery/
```

恢复后需要手动保存。

## 预览与图片导出

### 地图导航与内嵌预览

右上角“地图导航”与保存时生成的内嵌预览直接显示同一张引擎传统预览，包括地形、覆盖物和树木的预览色，以及红色方块起点。不会叠加编辑器的资源圆点、对象圆点或黑底编号。导航点击会按目标格高度定位到画布，矩形框表示当前视口。

- 传统地形由 VERA20k 的 `rmg::preview` 生成，尺寸由可玩区域的投影范围决定，每格贡献两个横向像素。导航与内嵌 `PreviewPack` 共用此图及标记，不包含导航视口框。
- 覆盖物颜色来自引擎的 SHP 帧头与规则，资源按密度着色。桥梁和树木也走引擎预览路径，不使用编辑器的替代色。
- 传统预览不受编辑器图层开关影响；导航采用最近邻缩放，保留原始像素。
- 按引擎可玩区域裁剪；高台、悬崖和地形高度不会缩小取景范围。超过 12 级的高地使用引擎预览色表的最高档（12），地图高度本身不变。
- 批量发布使用相同的内嵌预览生成方式。

### 选择导出方式

以下入口均位于“文件”菜单。

| 入口 | 输出内容 | 尺寸与显示设置 |
| --- | --- | --- |
| 导出高清地图预览图 PNG… | 调用 VERA20k 实际游戏渲染器，生成整张地图的高清图，包含未保存修改 | 最长边 4096 像素；不受编辑器图层与光照开关影响 |
| 导出内嵌预览原图 PNG… | 原样提取当前加载地图的 `PreviewPack`，包含自定义图片 | 保留原始尺寸和像素，无需游戏资源；不包含未保存修改 |

高清预览在后台导出，使用试玩设置中的 `vera20k.exe`，要求引擎支持 `--map-picture`，并需要可用的 GPU。引擎在隔离进程中加载当前地图快照与资源，绘制整个相机可见范围；地图自定义预览图片中的文字、装饰等不会参与重新渲染。失败时保留独立运行目录的日志，已有 PNG 不会被失败结果覆盖。

未保存的修改不会更新已加载的内嵌预览。没有内嵌预览时，请先保存地图生成预览，再重新加载后导出原图。

## 在 VERA20k 中试玩

点击“试玩”，选择遭遇战或单人任务，并指定 `vera20k.exe`；也可通过 `--playtest-exe PATH` 配置。试玩使用包含未保存修改的当前快照，输出写入独立目录。

任务声明了自定义文本或媒体时，试玩目录下的 `assets/` 会合并原版资源与任务资源，游戏从该目录加载。原游戏目录不变；大型归档优先使用硬链接，跨磁盘时复制，因此准备试玩可能需要额外时间和磁盘空间。

### 窗口、显示器与分辨率

默认使用窗口模式，勾选“全屏”可全屏启动。连接多个显示器时，面板会显示“显示器”选项，可选择启动屏幕，默认自动跟随系统。

“游戏内分辨率”通过本次试玩的 `[VERA] Zoom` 设置内部渲染分辨率，按所选显示器的实际像素列出完整档位及对应宽高。窗口和全屏使用同一列表；分辨率越高，画面越小，可见地图范围越大。

最大分辨率对应原始像素大小，使用游戏现有缩放档位，不改变窗口尺寸。调整游戏窗口后，对应分辨率也会变化。

### 玩家与设置保存

试玩请使用与编辑器依赖版本一致的 VERA20k 客户端。遭遇战人数由地图的有效玩家起点数决定。

试玩设置会随编辑器配置自动保存，重启后恢复游戏程序路径、显示器、全屏、分辨率、速度，以及玩家、电脑、难度和对局规则。通过 `--playtest-exe` 或 Mod 配置显式指定的游戏程序路径，优先于上次保存的路径。

## 字体与可访问性

界面按需使用系统字体补全中文、多语言文字和 Emoji；可通过 `--font PATH` 优先使用指定字体。

原生界面已启用 AccessKit，并为引用、数值和光照等表单输入补充可访问名称。

## 战役目录和任务发布

单人任务通过“任务制作”里的“战役目录与任务发布”编辑项目 JSON。项目保存关卡顺序、简报、文本和资源。各关地图可分别内嵌 `rules.wasm`，共享状态可通过原生 Global 变量传递。
